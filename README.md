# Latent Terrarium

A quiet pocket aquarium where five lives (**Mio, Nagi, Akari, Kuro, Hotaru**) drift, speak, and slowly settle their relationships over hours and days inside your browser.  
外部通信や生成AIを一切使わず、ブラウザの中だけで5人（ミオ・ナギ・あかり・クロ・ほたる）の関係性がゆっくり沈殿していく、小さな「言葉のアクアリウム」です。

- **Play in Browser**:
  - English: https://33kasp33-cpu.github.io/latent-terrarium/en/
  - 日本語: https://33kasp33-cpu.github.io/latent-terrarium/
- **Tech & Privacy**: Pure HTML5 Canvas + Web Audio API + local state machine. Zero external servers, zero telemetry, zero generative AI APIs. Progress is stored only in your browser (`localStorage` / `IndexedDB`). Supports PWA / offline play.
